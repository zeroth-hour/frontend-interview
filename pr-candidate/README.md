# Inspiration Gallery — PR review bundle

The proposed change is under **`apps/web/src/`** (four files) — that's what to review.
`PR_DESCRIPTION.md` is the author's write-up.

The rest of the files here (`package.json`, `vite.config.ts`, `main.tsx`, `index.css`,
`apps/web/src/data/mockInspirations.ts`) are a thin harness so you can run the feature in a
browser while reviewing.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL (usually `http://localhost:5173`).
